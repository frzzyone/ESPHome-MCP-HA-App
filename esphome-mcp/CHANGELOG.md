# Changelog

## 2026.09.0

- Initial release as a Home Assistant OS App (Add-on).
- Full support for ESPHome 2026.9+ Device Builder WebSocket command protocol.
- Streamable HTTP MCP server on port 8080.
- Automatic configuration pickup from Home Assistant UI (`/data/options.json`).
- Internal Docker DNS integration with the official ESPHome add-on (`http://5c53de3a-esphome:6052`).
- 15 MCP tools including device validation, YAML editing, OTA flashing, log streaming, and troubleshooting.
